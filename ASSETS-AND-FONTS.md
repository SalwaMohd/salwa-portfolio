# Assets and typography

## Fonts

The finished design uses system fonts: Georgia for display headings and the italic bold “salwa” logo; Arial/Helvetica for supporting text, with Times New Roman, serif and sans-serif fallbacks as defined in the original CSS. There are no downloaded font files, Google Fonts requests or font packages to supply. The existing font references, weights, sizes and letter spacing are preserved exactly. As on the current website, the visitor's available system fonts determine fallback rendering.

## Images and PDFs

All deployed image files and PDFs are included locally. The images used on the website are the existing PNG, JPEG, WebP and SVG assets; they have not been regenerated or recompressed for this export. The PDF files are the same website copies, including the CV and project presentations. Original Figma working files and source documents that were never part of the deployed website are not required for hosting and are not included.

## External references

Existing outbound links are preserved, including Behance, LinkedIn, email and any project reference links in supporting pages or documents. These are links rather than rendering dependencies. No external JavaScript or stylesheet is needed to display the portfolio.
